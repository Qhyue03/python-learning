## 方法论 v2：AI 时代怎么学（2026-09-02 修订）

目标岗位是**工业 3D 视觉应用工程师（应用层）**。这个岗位每天和代码打交道的三种方式：

1. **读**：看懂别人的代码、示例代码、开源仓库（占日常时间最多）
2. **判**：判断 AI 生成的代码对不对——AI 能写代码之后，"识别错误"的能力反而更值钱
3. **写**：亲手写核心小段逻辑（算法内核、数据处理），这是"能复述"红线的对象

所以练习按 **读-猜 → 改 → 写 → 讲** 四步走（说明在各周 README）：

- "看答案就会、自己写就不会"不是笨——那是**再认**和**回忆**的区别。对策就是先猜后跑（练判断）、改现成代码（练手感）、最后才白板写
- 语法不背，查 [docs/python-grammar.md](docs/python-grammar.md)，像查字典；查多了自然就记住了
- AI 使用规则（细化版）：
  - **9 月允许**：让 AI 解释概念、解释报错、解释别人的代码；让 AI 出题考自己
  - **9 月不允许**：直接要练习答案代码（要了也白要——再认 ≠ 会写）
  - **10 月起**：允许 AI 生成代码，但核心算法必须自己能复述、能复写；上传 GitHub 前做无 AI 复写
- MATLAB 是你的优势不是包袱：每学一个 Python 概念，想想 MATLAB 里对应的写法（[docs/matlab2numpy.md](docs/matlab2numpy.md)）

## 每日节奏（19:30–21:30）

- 前 20 分钟：**读-猜训练**（语法字典猜输出 / 读昨天的代码）
- 中间 80 分钟：当周练习（按 读-猜→改→写 顺序）
- 最后 20 分钟：写复盘笔记（记进 `notes/`，哪怕三行）

**卡壳规则**：先自己读报错（最后一行 + 行号）→ 30 分钟没进展 → 带"卡在哪级台阶、终端输出什么"去问 AI，只要解释不要答案。
