# 第 1 周（9/1–9/7）：语法基础

目标：变量、容器、控制流、函数写熟。所有题纯 Python（不用 numpy）。

每题一个文件：`ex01_xxx.py`，写完在终端跑通再下一题。

- [ ] ex01：f-string 打印杨辉三角前 10 行（练列表嵌套 + 循环）
- [ ] ex02：读入一串英文字符，用 dict 统计各字母出现次数，按次数降序打印（练字典）
- [ ] ex03：九九乘法表（对齐打印）+ 判断 100 以内素数（练循环、条件）
- [ ] ex04：手写 `my_linspace(start, stop, num)`（禁用 numpy），写完对比 `np.linspace` 验证误差 < 1e-15（练函数、默认参数）
- [ ] ex05：斐波那契——先写朴素递归，再加 dict 记忆化，计时对比 35 项（练递归、字典缓存）
- [ ] ex06：埃氏筛统计 10000 以内素数个数（练集合 set）
- [ ] ex07：纯 Python 实现矩阵乘法（嵌套列表，三重循环），随机 100×100 计时——**感受没有向量化有多慢，第 3 周会回来用 numpy 秒杀它**
- [ ] ex08（综合）：凯撒密码加密/解密函数 + 简单测试

## 自查标准

- 每个函数有 docstring 和类型不再乱（`type(x)` 能说清是什么）
- 能不查资料写出 for + range、列表推导式 `[x*x for x in range(10) if x%2==0]`
- 明白 `b = a` 和 `b = a.copy()` 的区别并能演示
