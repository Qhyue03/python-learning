## 练习的新格式（为什么变了）

每题四步，前三步都能"看答案验证"，最后一步才是白板写：

1. **读-猜**：看一段代码，先在纸上猜输出 → 运行验证。猜错 = 找到盲区，这是最有价值的时刻
2. **改**：给定能跑的代码，做小改动。改完运行确认
3. **写**：自己从零写。卡住就回到第 2 步的代码看一眼结构（不抄，看一眼合上）
4. **讲**：合上屏幕，用一句话说出"这段代码在干嘛"。说不出来 = 还不是你的

## ex01 杨辉三角（组合题 · 拆解见 hint 文档）

**读-猜**（先做这个，和杨辉三角同款技能但更简单）：

```python
for i in range(1, 6):
    stars = "*" * i
    print(f"{stars:^10}")
```

猜输出 → 运行 → 你猜对了吗？如果对了，居中技巧你已经有了（这题的格式化部分通关）。

**读-猜 2**：

```python
rows = [[1], [1, 1], [1, 2, 1]]
for row in rows:
    text = ""
    for x in row:
        text = text + str(x) + " "
    print(f"{text:^20}")
```

猜输出 → 运行。这两段代码拼起来 = 杨辉三角的"显示部分"。

**改**：把第二段代码改成打印 `[[1], [1, 1], [1, 2, 1], [1, 3, 3, 1]]`（手写加一行数据）；再把 `^20` 改成 `^30` 看效果。

**写**：完整杨辉三角前 10 行。生成数据的思路见 [ex01_hint.md](ex01_hint.md) 台阶 C（中文伪代码在那里）。

## ex02 字母计数（字典入门）

**读-猜**：

```python
d = {"a": 1, "b": 3}
print(d["b"])
d["c"] = 2
print(d)
print(d.get("z", 0))    # get：键不存在时返回默认值，不报错
```

**改**：把 `d` 里的 "b" 的值改成 10 并打印。

**写**：统计 `"python is fun"` 里每个字母出现几次，按次数从多到少打印。
提示：遍历字符串 `for ch in s:`，用 `d[ch] = d.get(ch, 0) + 1` 这个累加模式（和 w0-4 的累加器同一个思想，只是盒子从数字换成字典）；排序用 `sorted(d.items(), key=lambda kv: kv[1], reverse=True)`——这行先照抄，lambda 10 月再深究。

## ex03 乘法表 + 素数（循环组合）

**读-猜**：

```python
for i in range(1, 4):
    for j in range(1, i + 1):     # 内层上限跟着外层走
        print(f"{j}*{i}={i*j}", end="  ")
    print()                        # 空print = 换行
```

**写**：九九乘法表（对齐可参考 f-string 的 `:>4`）；判断 100 以内素数（素数 = 只能被 1 和自己整除：对 n 试除 2 到 int(n**0.5)，都不整除则是素数）。

## ex04 手写 my_linspace（函数 + 循环）

**读-猜**：

```python
def my_range_like(start, stop, num):
    step = (stop - start) / (num - 1)
    out = []
    for i in range(num):
        out.append(start + i * step)
    return out

print(my_range_like(0, 1, 5))
```

**写**：仿照它实现 `my_linspace(start, stop, num)`，然后用 `abs(my_linspace(0,1,5)[2] - 0.25) < 1e-15` 验证。这就是你 MATLAB 天天用的 `linspace`——9 月大作业里会用到。
