# ex01 拆解：杨辉三角 · 四级台阶

> 不是一道题，是四道小题。每一级做完都能运行、都能看到东西。
> 建议今晚只做 A + B（丑但能看），明天 C + D（会动起来）。

## 台阶 A：先让形状对（只练 f-string 居中）

不看任何数据，先打印一个 5 行的**星号金字塔**：

```
    *
   ***
  *****
 *******
*********
```

- 用到的：一个 for 循环 + `f"{s:^20}"`（s 是拼好的星号字符串，`:^20` 居中）
- 星号怎么拼：`"*" * 3` 会得到 `"***"`（Python 的字符串乘法，试一下）
- **完成标志**：终端出现居中的星号金字塔
- 做完这级你就掌握了"整行居中"的技巧，后面直接复用

## 台阶 B：让数字对（数据手写，不算）

不动脑子算，把前 5 行**手动硬编码**：

```python
triangle = [[1], [1, 1], [1, 2, 1], [1, 3, 3, 1], [1, 4, 6, 4, 1]]
```

然后用 for 循环逐行打印，目标是输出：

```
     1
    1 1
   1 2 1
  1 3 3 1
 1 4 6 4 1
```

- 新知识点只有一个：数字怎么拼成 `"1 2 1"` 这种字符串？
  提示：`str(x)` 能把数字变字符串，字符串能用 `+` 拼接；或者 f-string 里 `f"{x} "` 也行
- 别忘了套上台阶 A 的居中
- **完成标志**：终端出现居中的数字金字塔（哪怕只有 5 行、哪怕代码很丑）

> 🎉 到这里"杨辉三角"这个作业其实已经完成一半了——形状和数据都会显示了。
> 剩下的只是把"手写数据"换成"机器算数据"，那是台阶 C 的事。

## 台阶 C：让机器算数据（真正的思维题，明天攻）

核心问题一句话：**知道上一行，怎么算出下一行？**

用具体例子找感觉，上一行是 `[1, 2, 1]` 时：

```
相邻两数相加：1+2=3，2+1=3
下一行 = [1] + [3, 3] + [1] = [1, 3, 3, 1]
```

要写的逻辑（中文伪代码，翻译成 Python 是你的作业）：

```
新一行 从 [1] 开始
对上一行的下标 i 从 0 走到 倒数第二个：
    把 上一行[i] + 上一行[i+1] 追加进 新一行
结尾补上 1
```

- 用到的：`len()`、下标访问 `row[i]`、`append()`——全是 w0-3 练过的
- 先单独验证：写死了 `row = [1, 2, 1]`，打印算出的新行是不是 `[1, 3, 3, 1]`，对了再继续
- **完成标志**：随便换一行（如 `[1,4,6,4,1]`）都能算出正确的下一行

## 台阶 D：组装（10 行全流程）

- 从 `triangle = [[1]]` 开始，循环 9 次，每次用台阶 C 的逻辑算出新行 append 进去
- 最后用台阶 B 的打印方式输出 10 行
- **完成标志**：10 行杨辉三角居中显示，此时 ex01 正式通关 ✅
