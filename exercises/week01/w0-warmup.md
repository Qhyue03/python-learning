# 第 0 晚热身（9/1）：唤醒手感

> C++ 底子还在但两三年没用？正常。下面 5 个台阶每个 5-10 分钟，
> 一晚上做完 w0-1 到 w0-4 就是合格，w0-5 可以留到明天。
> 每个台阶一个文件，写完 Ctrl+S → 右上角 ▶ 运行。

- [ ] w0-1 变量 + f-string（`w0_1_hello.py`）：定义姓名和年龄两个变量，用 f-string 打印 `我是XXX，今年XX岁`
- [ ] w0-2 for + range（`w0_2_for.py`）：依次打印 1 到 10；再打印 10 到 1；再只打印 0 到 20 里的偶数（提示：range 有第三个参数）
- [ ] w0-3 列表入门（`w0_3_list.py`）：建一个空列表，循环 append 进 1~5，然后打印整个列表、第一个元素、列表长度
- [ ] w0-4 累加器（`w0_4_sum.py`）：用循环算 1+2+…+100 的和并打印（C++ 课堂经典题，唤醒记忆专用）
- [ ] w0-5 嵌套预备（`w0_5_nested.py`）：用循环生成 `[[1], [1,2], [1,2,3]]` 并逐行打印——做完这个，杨辉三角就只差"加法规则"了

完成后杨辉三角（ex01）放到**周四**再攻，它只是 w0-5 再多一个加法规则而已。
